# Mgroup Shopify Developer Tools

Free, no-login Shopify tools by [Mgroup](https://mgroupweb.com/) — a Shopify development agency and certified Shopify Select Partner since 2016. Live at **https://mgroupweb.github.io/**

| Tool | What it does |
|---|---|
| [Shopify Plus Pricing Calculator](https://mgroupweb.github.io/shopify-plus-pricing-calculator/) | Models the platform fee (flat vs 0.25% revenue model), gateway fees, apps and development into a monthly and first-year TCO |
| [Shopify Migration Checklist](https://mgroupweb.github.io/shopify-migration-checklist/) | 9 phases / 70+ tasks from pre-migration SEO audit to post-launch monitoring, progress saved locally, export as plan |
| [Shopify Liquid Snippets](https://mgroupweb.github.io/shopify-liquid-snippets/) | Copy-paste Online Store 2.0 Liquid: section schema, free-shipping bar, metafields, responsive images, badges, breadcrumbs |

## Stack

Static HTML/CSS/JS, no build step. Design tokens follow the Mgroup design system (navy `#1F2544`, cyan `#40D0FF`, indigo `#5A58E2`, Fivo Sans). Deployed with GitHub Pages from `main`.

## Contributing

Found a bug in a snippet or a pricing figure that changed? Open an issue or a pull request. Snippets live in `assets/js/snippets.js`, checklist tasks in `assets/js/checklist.js`, calculator logic in `assets/js/calculator.js`.
