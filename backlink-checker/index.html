How we use it

The four-layer backlink check we run before paying for a placement

Most link sellers show a domain metric and stop there. We check four layers before any money moves: the rel attribute on links inside recent articles (a site whose posts are all nofollow will nofollow yours too), robots at page and header level, whether the link is a real <a href> in the HTML rather than injected by script or wrapped in a tracking redirect, and where it sits — content beats footer every time. A high authority score with a failing layer is still a wasted placement.

The profile section adds the donor-side signals we look at: a reasonable Open PageRank, referring domains that grow steadily rather than in spikes, and a low Moz Spam Score. FAQ

Backlink checker FAQ

Can I see the full list of backlinks for any domain here?

No — and no free tool really can. Complete backlink lists come from paid link indexes (Ahrefs, Moz Links API, Semrush, Majestic); free checkers that show lists resell those APIs with tight caps. This page gives you the free part honestly: link-profile metrics from Open PageRank (Common Crawl), Moz DA/PA/Spam via our proxy, the Tranco ranking, and a verifier that inspects the exact pages you already know about.

What does the backlink verifier check?

It fetches the source page like a crawler and reports the HTTP status, whether an actual to your domain exists in the HTML, the rel attribute (follow, nofollow, sponsored, ugc), the anchor text, where the link sits (content, nav, footer), whether the page is indexable (meta robots / X-Robots-Tag) and where its canonical points. Links injected by JavaScript are not seen, which is the same thing Google ignores for link equity.

Why does a link show as ‘No link’ when I can see it on the page?

Usually the link is rendered by JavaScript after load, sits behind a redirect script (r.example.com/redirect?...) or is a plain-text mention without an anchor tag. None of those pass authority. Some sites also serve different HTML to crawlers; the verifier identifies itself as a bot.

Is a nofollow backlink worthless?

Not worthless, but it passes no ranking signal by itself. Nofollow links from real sites still bring referral traffic, brand mentions that AI answer engines pick up, and diversity in your link profile. For ranking, prioritise dofollow links inside editorial content on topically related sites.

Do you store the URLs I check?

No. Source pages are fetched by our Cloudflare Worker on demand and the result is returned to your browser; nothing is logged or kept. Link-profile metrics are cached per domain for up to 30 days so repeated checks do not spend API quota.
